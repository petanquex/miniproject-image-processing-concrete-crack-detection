## ระบบตรวจจับรอยร้าวบนพื้นผิวคอนกรีต (Concrete Crack Detection)

### 1. ปัญหาที่สนใจ แรงบันดาลใจ และแหล่งที่มา

เหตุการณ์แผ่นดินไหวที่ส่งผลกระทบต่อประเทศไทยเมื่อปีที่ผ่านมา ได้สร้างความตื่นตัวด้านความปลอดภัยของโครงสร้างอาคารและโครงสร้างพื้นฐานอย่างมาก รอยร้าวบนผนังหรือเสาคอนกรีตเป็นหนึ่งในสัญญาณเตือนแรกสุดของความเสื่อมสภาพทางโครงสร้าง แต่การตรวจสอบด้วยสายตามนุษย์ (Visual Inspection) ในพื้นที่ขนาดใหญ่หรือจุดที่เข้าถึงยากนั้นใช้เวลานานและเสี่ยงต่อความผิดพลาด จึงเกิดแรงบันดาลใจในการนำเทคโนโลยีคอมพิวเตอร์มาช่วยวิเคราะห์รอยร้าว เพื่อประเมินความปลอดภัยเบื้องต้นได้อย่างรวดเร็วและแม่นยำยิ่งขึ้น

### 2. จุดประสงค์ของงานวิจัย

เพื่อพัฒนาระบบประมวลผลภาพ (Image Processing) ที่สามารถตรวจจับและดึงลักษณะเส้นขอบของรอยร้าวบนพื้นผิวคอนกรีตออกมาได้อย่างอัตโนมัติ โดยระบบจะต้องแยกแยะความแตกต่างระหว่าง "รอยร้าวที่เกิดจากความเสียหายทางโครงสร้าง" กับ "พื้นผิวขรุขระปกติหรือรอยเปื้อนบนคอนกรีต" ได้

### 3. ขอบเขตของงานวิจัย หรือเป้าหมายที่จะได้หลังจากการทำวิจัย

- **เป้าหมาย:** ได้โปรแกรมต้นแบบที่สามารถรับภาพถ่ายคอนกรีตและตีกรอบหรือไฮไลต์บริเวณที่เป็นรอยร้าวได้
    
- **สเกลงาน:** โครงการนี้ออกแบบมาให้เหมาะสมกับการแบ่งงานในทีมขนาด 2-3 คน โดยจะแบ่งพาร์ทการเตรียมภาพ, การปรับแต่งโค้ด (Algorithm Tuning), และการทำสรุปผล
    
- **ข้อมูล (Dataset):** ใช้ชุดข้อมูลสาธารณะที่มีภาพเฉลย (Ground-Truth Mask) ระดับพิกเซล เช่น CrackForest (CFD), Crack500 หรือ DeepCrack เพื่อให้สามารถวัดผลการแยกรอยร้าวได้อย่างแม่นยำ โดยเน้นภาพรอยร้าวที่ถ่ายในสภาพแสงที่ควบคุมได้ระดับหนึ่ง
    
- **เทคนิค:** ใช้เทคนิคการประมวลผลภาพแบบพื้นฐาน (Traditional Image Processing) เป็นหลัก โดยยังไม่ใช้โมเดล Deep Learning ขนาดใหญ่ เพื่อพิสูจน์ลอจิกทางคณิตศาสตร์ของการจัดการภาพ
    

### 4. นำเสนอบทความวิจัยในอดีต (Literature Review)

ในการค้นคว้าเปเปอร์หรือบทความวิจัย (PDF) ควรมุ่งเน้นไปที่หัวข้อต่อไปนี้:

- เปเปอร์ที่เปรียบเทียบแนวทางการแยกรอยร้าวแบบ **Edge-based** (เช่น Canny, Sobel) กับแบบ **Threshold-based** (เช่น Otsu's, Adaptive Thresholding) เพื่อเป็นเหตุผลในการเลือกเทคนิคหลักของโครงการ
    
- เปเปอร์เกี่ยวกับการใช้ **Adaptive/Otsu's Thresholding** เพื่อแยกพื้นหลัง (เนื้อคอนกรีต) ออกจากวัตถุที่สนใจ (รอยร้าวสีเข้ม) โดยเฉพาะในสภาพแสงที่ไม่สม่ำเสมอ
    
- เปเปอร์ที่นำเสนอการใช้ **Morphological Operations** เพื่อเชื่อมต่อเส้นรอยร้าวที่ขาดหายจากการถ่ายภาพให้เป็นเส้นที่สมบูรณ์ และลบสัญญาณรบกวน
    

### 5. นำเสนอขั้นตอน และกระบวนการที่เลือกใช้

กระบวนการวิเคราะห์ภาพ (Image Processing Pipeline) จะแบ่งเป็น 4 ขั้นตอนหลัก:

1. **Image Pre-processing:** แปลงภาพสีเป็นภาพขาวดำ (Grayscale) จากนั้นใช้ฟิลเตอร์ลดสัญญาณรบกวน (เช่น Gaussian Blur) และปรับคอนทราสต์ (Histogram Equalization / CLAHE) เพื่อให้รอยร้าวสีเข้มตัดกับผิวคอนกรีตสีเทาชัดเจนขึ้น
    
2. **Segmentation:** ใช้เทคนิค Adaptive Thresholding (เปรียบเทียบกับ Otsu's) เพื่อแยกพิกเซลที่มืดกว่าปกติ (รอยร้าว) ออกจากพื้นหลัง ได้ผลลัพธ์เป็นภาพ Binary Mask เบื้องต้น
    
3. **Morphological Filtering:** รอยร้าวบางจุดอาจขาดตอน จึงใช้ Closing (Dilation ตามด้วย Erosion) เพื่อเชื่อมรอยร้าวให้เป็นเส้นเดียวกัน และใช้ Opening (Erosion ตามด้วย Dilation) เพื่อลบจุดรบกวน (Noise) เล็กๆ ที่ไม่ใช่รอยร้าวทิ้งไป
    
4. **Shape Analysis & Filtering:** ดึงเส้นขอบ (Contour) ของแต่ละบริเวณที่เหลือ แล้วกรองด้วยคุณสมบัติเชิงรูปทรง เช่น พื้นที่ (Area) และอัตราส่วนความยาวต่อความกว้าง (Aspect Ratio) เนื่องจากรอยร้าวจริงมักเป็นเส้นเรียวยาว ต่างจากรูพรุนหรือรอยเปื้อนที่เป็นจุดกลม เพื่อให้ได้ Mask สุดท้ายที่เป็นรอยร้าวจริง
    

### 6. ความคาดหวังของผลลัพธ์ที่ได้จากการทดลองเบื้องต้น

คาดว่าโปรแกรมจะสามารถสร้างภาพหน้ากาก (Binary Mask) ที่ไฮไลต์เฉพาะเส้นรอยร้าวบนคอนกรีตได้อย่างถูกต้อง โดยสามารถกรอง Noise ที่เกิดจากความขรุขระ รูพรุน หรือเงาตกกระทบบนผิวคอนกรีตออกไปได้ระดับหนึ่ง

### 7. หลักการที่จะใช้ประเมินผลลัพธ์เบื้องต้น

จะประเมินผลในระดับพิกเซล (Pixel-level) โดยเปรียบเทียบภาพ Binary Mask ที่โปรแกรมสร้างขึ้นกับภาพเฉลย (Ground-Truth Mask) แล้วสร้าง **Confusion Matrix** ระดับพิกเซล (นับ True/False Positive/Negative ของแต่ละพิกเซล) เพื่อคำนวณค่า:

- **Precision:** สัดส่วนพิกเซลที่ทายว่าเป็นรอยร้าวแล้วถูกต้องจริง (ลด False Positive จากรอยเปื้อน/เงา)
    
- **Recall:** สัดส่วนพิกเซลรอยร้าวจริงที่โปรแกรมตรวจจับได้ (ลด False Negative หรือรอยร้าวที่หลุดรอด)
    
- **IoU (Jaccard Index) และ Dice / F1-Score:** วัดระดับการซ้อนทับระหว่าง Mask ที่ทำนายกับภาพเฉลย ซึ่งเป็นตัวชี้วัดมาตรฐานของงาน Segmentation ที่เหมาะกับข้อมูลรอยร้าวที่มีพิกเซลไม่สมดุล (Class Imbalance) มากกว่าการใช้ Accuracy เพียงอย่างเดียว
    

### 8. นำเสนอความคิดในการต่อยอดงานวิจัยหรือโครงการ

งานวิจัยนี้สามารถนำไปต่อยอดเป็นการพัฒนาระบบ IoT หรือ Edge AI ได้ในอนาคต โดยนำอัลกอริทึมที่เขียนไปปรับแต่งให้ทำงานเบาลง (Optimize) เพื่อนำไปฝังลงบนไมโครคอนโทรลเลอร์ขนาดเล็ก เช่น ESP32, STM32 หรือแม้แต่บอร์ด FPGA จากนั้นนำบอร์ดไปติดตั้งร่วมกับกล้องและโดรนสำรวจ (Drone Inspection) เพื่อใช้บินถ่ายภาพรอยร้าวตามซอกตึก หรือใต้สะพานที่คนเข้าถึงยาก และส่งข้อมูลแจ้งเตือนพร้อมพิกัดเข้าสู่ระบบส่วนกลางได้ทันที
